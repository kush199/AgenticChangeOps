# Sample Codebase (invented)

This folder holds two small, entirely invented systems used only as reading material for the
Architect agent's optional read-only tools:

- `orders-service/`: accepts orders, checks stock, tracks order status.
- `billing-portal/`: lists invoices, decides payment reminders, exports statements.

Everything here is made up. There are no real names, credentials, addresses or hosts. The files are
plain text pseudo-source: they are not compiled, run or tested, and they are not part of the
solution. The tools can only read them.
